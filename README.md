# Railway Reservation System 🚆

## About the Project
I developed this Railway Reservation System project using C programming. The project focuses on applying Data Structures and Algorithms (DSA) to manage railway reservations and related operations.

## Features
- User registration and login
- View available trains
- Book and cancel tickets
- Check booking details and PNR
- Waiting list management
- Store user and reservation details using file handling
- Send mail for successful reservation

## Technologies Used
- **Programming Language:** C
- **Data Structures:** Linked Lists, Queues, Structures, and Hashing
- **Algorithms:** Searching and reservation management
- **File Handling:** To store and retrieve data

## How to Run
1. Clone or download this repository.
2. Open the project in a C-supported IDE.
3. Compile `Railwar_res.c` using a compatible C compiler.
4. Run the compiled program.
